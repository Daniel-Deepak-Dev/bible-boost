# EPIC-06 — Import and export

**Goal:** get notes out of the extension in useful shapes, and back in without
losing anything.

This epic also carries the project's main answer to its biggest weakness. Notes
live only in this browser profile; clearing browsing data or removing the
extension destroys them. Export **is** the backup story until sync exists, which
is why T-049 is part of this epic and not a nicety.

## Format decisions

XML was in the original request and was dropped: it has no consumer for Bible
study notes. Markdown replaced it, because that is where these notes actually
want to end up.

| Format | Role |
|---|---|
| **JSON** | lossless, the round-trip and backup format |
| **CSV** | spreadsheets. Lossy and flat, by nature |
| **Markdown** | Obsidian, Notion, Logseq. One-way |

## Definition of done

- [ ] Export to all three formats, for everything or a selection
- [ ] JSON round-trips with zero loss — including both verse texts and timestamps
- [ ] CSV opens in Excel with Tamil rendering correctly
- [ ] Markdown opens in Obsidian with topics as structure
- [ ] Import previews before it applies
- [ ] Import cannot corrupt the database or inject content
- [ ] The user is reminded to back up

## The rule that governs this whole epic

**An imported file is untrusted input.** It may be hand-edited, generated by
something else, truncated, or hostile. Every record goes through the same
validator as the create path (T-048). Nothing from a file reaches IndexedDB
unvalidated, and nothing from a file reaches the DOM as HTML.
